개인정보처리방침

개발자: 베지밀 · 시행일 및 최종 수정일: 2026년 9월 21일
대상 앱: 오늘도 보글보글 · com.hotpotstudio.bogeulbogeul

베지밀(이하 “개발자”)은 오늘도 보글보글(이하 “앱”) 이용 과정에서 처리되는 정보와 이용자의 선택 방법을 다음과 같이 안내합니다. 이 방침은 Android 앱 버전 1.1의 기능을 기준으로 합니다.

앱은 이름·이메일·전화번호를 입력하는 회원가입을 요구하지 않습니다. 소스 즐겨찾기는 기기에 저장됩니다. 온라인 협동을 선택하면 Unity의 익명 인증 및 멀티플레이 서비스를 통해 플레이어 식별자와 연결 정보가 처리됩니다.

1. 기기에 저장되는 정보

온라인 기능 이용 전에 만 나이를 입력할 수 있습니다. 입력한 정확한 나이와 생년월일은 저장하거나 전송하지 않습니다. 만 16세 미만 여부에 따른 이용 구분만 기기에 보관합니다. 만 16세 이상 이용자도 앱을 새로 실행하면 다시 확인하며, 온라인 사용 동의는 실행 중에만 유지됩니다. 만 16세 미만으로 확인한 기기에는 나이를 다시 입력해 온라인 기능을 해제하는 버튼을 제공하지 않습니다.

소스 노트의 즐겨찾기 선택은 기기 내 앱 저장공간에 저장됩니다. 이 즐겨찾기를 개발자 서버로 전송하거나 다른 플레이어에게 공유하는 기능은 없습니다. 온라인 협동에 사용되는 Unity 인증 세션 정보도 재접속을 위해 기기에 저장될 수 있습니다.

즐겨찾기는 앱에서 선택을 해제할 수 있습니다. Android 설정에서 앱의 저장공간 데이터를 삭제하면 해당 기기의 앱 저장 정보가 초기화됩니다. 앱 삭제만으로 서비스 제공자에게 저장된 온라인 정보까지 삭제되는 것은 아닙니다.

2. 온라인 협동 및 로컬 연결

온라인 협동에서는 Unity Authentication과 Unity Multiplayer Services(Relay 및 세션 서비스)를 사용합니다. 별도의 아이디나 비밀번호 입력 없이 익명 플레이어가 생성되거나 기존 세션이 복구됩니다.

  • 처리 정보: 익명 플레이어 ID, 인증 토큰, IP 주소 및 IP로 추정되는 대략적인 위치, 세션 식별자·참가 코드, 서비스 이용 활동 및 연결 성능 정보.
  • 목적: 참가자 식별과 인증 정보 관리, 방 생성·참가, 연결 유지, 협동 게임 진행 동기화, 서비스 운영 분석 및 성능 관리.
  • 게임 중 공유: 조리 명령, 재료·진행 상태 등 협동 플레이에 필요한 게임 정보가 함께 접속한 플레이어에게 전달됩니다.
  • 처리 제공자: Unity Technologies 및 관련 서비스 운영 법인. 서비스 운영에 따라 이용자 거주 국가 밖의 서버에서 정보가 처리될 수 있습니다.

앱에는 자유 입력 채팅이나 음성 채팅 기능이 없습니다. 로컬 연결은 입력한 IP 주소로 기기끼리 연결하며, 해당 연결 경로에서는 Unity 익명 로그인과 Relay를 사용하지 않습니다. 온라인 협동을 선택하지 않고 1인 플레이를 이용할 수 있습니다.

3. 광고 및 기타 SDK

버전 1.1은 광고를 표시하지 않으며 Unity LevelPlay, Unity Ads 및 광고 ID 라이브러리를 포함하지 않습니다. 향후 광고를 추가하는 경우 실제 처리 정보, 목적 및 필요한 선택 절차를 이 방침에 반영합니다.

앱 코드에는 별도의 이용 분석 또는 오류 보고 SDK 연동이 구현되어 있지 않습니다. 앱은 연락처, 사진, 마이크, 카메라 또는 기기의 정밀 위치에 대한 접근을 요구하지 않습니다.

4. 문의 시 처리되는 정보

이메일로 문의하면 발신 이메일 주소와 이용자가 보낸 문의 내용 및 첨부 자료를 문의 응대와 문제 해결을 위해 처리합니다. 비밀번호나 불필요한 민감정보는 보내지 마세요. 문의 정보는 응대 목적에 필요한 동안 보관하며, 목적이 끝나면 삭제합니다. 법령에 따른 보관 의무가 있는 경우에는 해당 의무에 따릅니다.

5. 제공·보관 및 삭제 요청

삭제 요청 방법: euna.jung.programmer@gmail.com으로 제목에 “오늘도 보글보글 데이터 삭제 요청”을 기재하여 보내 주세요. 삭제하려는 정보의 종류(온라인 협동 정보 또는 문의 내역)를 알려 주시면 확인 절차를 안내합니다. 인증 비밀번호나 토큰은 보내지 마세요.

개발자는 개인정보를 판매하지 않습니다. 온라인 기능 제공에 필요한 정보는 위에 명시한 Unity 서비스를 통해 처리됩니다. 법령에 따라 요구되는 경우에는 필요한 범위에서 정보를 제공할 수 있습니다.

기기 내 정보는 이용자가 삭제할 때까지 보관됩니다. Unity Relay의 개인정보 보관 기간은 해당 서비스 공식 문서상 30일입니다. 인증 계정과 다른 서비스의 정보는 각각의 서비스 보관·삭제 기준에 따르며, Relay의 보관 기간과 같다는 뜻은 아닙니다. 익명 인증 정보는 앱을 삭제한 후에도 서비스에 남을 수 있습니다.

열람·정정·삭제·처리정지 요청은 아래 연락처로 보낼 수 있습니다. 개발자는 요청 대상과 본인 여부를 확인하는 데 필요한 최소한의 정보를 안내하고, 필요한 경우 Unity의 관련 절차를 통해 처리합니다. 기기 데이터를 먼저 삭제하면 익명 플레이어를 식별하기 어려울 수 있으므로 온라인 정보 삭제를 원하면 먼저 문의해 주세요.

온라인에 접속한 이용자는 앱의 “개인정보 · 온라인 설정 → 개인정보처리방침”에서 현재 익명 ID를 확인하고 “온라인 ID 삭제”를 요청할 수 있습니다. 삭제 확인을 누르면 협동 연결을 종료하고 Unity Authentication 계정을 삭제합니다. 이 작업으로 Relay 등의 서비스 기록이 동시에 삭제되는 것은 아니므로 해당 기록의 삭제는 문의처로 요청해 주세요. 삭제된 인증 ID는 복구할 수 없고 다시 온라인을 이용하면 새로운 ID가 생성됩니다.

Unity 인증 요청은 서비스의 보안 연결을 사용합니다. 같은 Wi-Fi 직접 연결의 게임 데이터에는 앱 수준의 전송 암호화를 제공하지 않으므로 신뢰할 수 있는 네트워크와 아는 사람끼리 이용해 주세요. 참가 코드와 인증 토큰은 공개하지 말아 주세요.

6. 아동의 개인정보

아동도 1인 조리, 소스 노트 및 같은 Wi-Fi 협동을 이용할 수 있습니다. 앱의 운영 기준상 만 16세 미만 또는 연령 미확인 이용자에게는 인터넷 협동과 외부 참고 자료 링크를 제공하지 않으며 Unity 온라인 인증·Relay를 초기화하지 않습니다. 같은 Wi-Fi 모드는 참여 기기끼리 IP 주소와 게임 진행 정보를 교환하고 개발자의 온라인 서버를 거치지 않습니다.

앱은 검증된 보호자 동의를 수집하는 기능을 제공하지 않으며 단순한 확인 버튼을 보호자 동의로 간주하지 않습니다. 함께 사용하는 기기는 이용자가 바뀌기 전에 “온라인 사용 중지”를 선택해 주세요. 아동의 정보 처리나 삭제에 대한 보호자 문의는 아래 연락처로 접수합니다.
